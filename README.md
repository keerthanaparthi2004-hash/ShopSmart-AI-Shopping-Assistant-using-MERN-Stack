### Features Implemented 
- **Auth**: Per-user cart & wishlist using ProtectedRoute - data in localStorage per user email
- **Components Reuse**: SearchBar component used in Navbar, ProductFilter used in Shop, CartItem component used in Cart.jsx
- **AI Assistant**: Tamil budget parse (₹5000 ku) + Product matching + one-line Tamil reason + Add to Cart
- **Theme**: Dark Green #052e16 theme - all backgrounds, buttons, cards updated
- **Responsive**: Mobile & Desktop fully responsive
- **CRUD**: Cart add/remove/update qty, Wishlist add/remove, User auth signup/login

### Tech Stack
React + Vite + Tailwind + React Router + LocalStorage

### How to Run
npm install
npm run dev
